An original X post introducing @crisxai5 as a must-follow AI and crypto expert — AI agents, crypto insights, Web3 innovation. The card spotlights his signature line: "the pages nobody's quoting", the numbers behind the BTC headlines that everyone else skips past.

The entry is the post itself: https://x.com/call_me_slyy/status/2125739172837118212

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only) copies `POST.json` from the repository root to `/output/POST.json`, where the gate reads it. The house reads the post's public engagement counts (likes + reposts + quotes) from X directly.
